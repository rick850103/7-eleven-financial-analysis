# 統一超商（2912）財務深度分析系統

## 專案概述

針對統一超商（台股代號：2912）2023至2025年度財務報表進行系統性深度分析，
整合 Excel Power Query、MySQL 與 Power BI 建構完整的財務數據分析管道，
從原始財報資料清洗、結構化儲存到互動式視覺化呈現一條龍完成。

## 技術架構
MOPS財報下載 → Excel Power Query清洗 → MySQL結構化儲存 → Power BI視覺化
Excel Power Query : 原始財報清洗、財務比率計算、YoY比較表 
MySQL : 結構化資料儲存、四張資料表管理 
Power BI : 互動式儀表板、趨勢分析、異常警示 

## 資料來源
- **來源**：公開資訊觀測站（MOPS）
- **年度**：2023、2024、2025
- **報表**：損益表、資產負債表、現金流量表

## 財務比率計算
| 毛利率 | 營業毛利 ÷ 營業收入 |
| 營業利益率 | 營業利益 ÷ 營業收入 |
| 淨利率 | 本期淨利 ÷ 營業收入 |
| ROE | 本期淨利 ÷ 股東權益 |
| ROA | 本期淨利 ÷ 資產總額 |
| 負債比率 | 負債總額 ÷ 資產總額 |
| 流動比率 | 流動資產 ÷ 流動負債 |
| 存貨週轉次數 | 營業成本 ÷ 平均存貨 |

## 核心分析發現

### 獲利能力：營收成長但獲利端全面惡化

統一超商呈現「營收穩定成長、毛利率維持34%、但費用控制失守導致獲利端惡化」格局。
毛利率三年穩定維持34%，顯示零售端定價能力與供應鏈管理無虞。
然而營業利益率從4.34%連續下滑至3.97%，根源在於推銷與管理費用佔比持續擴張，
反映展店策略帶動的營運成本增速超過營收增速。

### 流動性：短期償債壓力持續上升

流動比率三年連續下滑（87.29%→86.08%→78.40%），
已低於零售業100%一般警戒線，顯示短期資產覆蓋短期負債的能力逐年收窄。
現金調度彈性下降，需持續關注營運資金管理效率。

### 負債結構：IFRS 16 租賃效應需審慎解讀

負債比率81.91%表面偏高，主因為 IFRS 16 將營業租賃負債強制入表，
統一超商全台門市展店策略導致使用權資產與租賃負債同步膨脹，
並非財務槓桿惡化的訊號，但利率變動對財務成本的影響仍需持續追蹤。

### 資產運用效率：展店擴張稀釋報酬率

ROA 從5.09%降至4.56%（YoY -10.54%），
在資產規模持續擴張的背景下，單位資產創造獲利的能力明顯退步。
若新展店點短期內無法達到損益平衡，資本配置效益將持續承壓。
